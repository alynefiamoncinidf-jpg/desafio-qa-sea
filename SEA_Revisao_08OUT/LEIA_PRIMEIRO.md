# Como usar esta revisão

1. Este pacote contém a revisão do projeto e documentos em Markdown. Não é confirmação de atualização do GitHub nem substitui automaticamente arquivos no computador.
2. Compare/substitua na pasta do projeto: package.json, cypress/e2e/defeitos.cy.js, cypress/e2e/api-listagem.cy.js, README.md, VALIDACAO.md e DIARIO_IA.md. Inclua RELATORIO_REVISAO.md e PLANO_E_ESTRATEGIA.md. RETESTE_04OUT.md é histórico.
3. Formulario.cy.js, configuração e lockfile foram preservados. O ajuste de API é apenas formatação. As asserções não foram alteradas após os resultados recebidos.
4. Envie esses arquivos ao GitHub mantendo cypress/e2e para os testes. Não envie node_modules. O pacote não contém node_modules.
5. O PDF anterior não foi atualizado por este pacote; não o apresente como se contivesse os resultados de 07/10–08/10. O relatório atualizado deste pacote está em RELATORIO_REVISAO.md.
6. Antes da entrega externa, confira o documento original do desafio, os links, a leitura dos documentos e as evidências. As capturas automáticas recentes estão no Windows em cypress/screenshots e ainda precisam ser reunidas.
